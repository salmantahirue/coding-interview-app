# 10 Coding Questions × 31 Real-Time Scenarios

A React learning guide for coding interviews, based on **"10 Coding Questions Asked In Interviews (31 Real-Time Scenarios) From My 200+ Interview Experience"** ([video](https://www.youtube.com/watch?v=UFAwAw-7Zpw)).

## Features

- **10 coding problems** with **31 real-time scenarios**, each with:
  - Problem statement and example
  - Full solution (code)
  - Design patterns and data structures/algorithms used
  - Time and space complexity
  - Good vs bad data structure/algorithm choices
  - Trace table (dry run) where applicable

- **Learning guide**: Problem → Solution → Pattern → DSA
- **Trace table guide**: How to dry run algorithms with trace tables (based on [Trace Table Tutorial](https://www.youtube.com/watch?v=q8cKb-nSZuA))
- **Browse by DSA**: Problems categorized by Array, Hash Map, Two Pointers, DP, Graph, etc.
- **Good vs bad**: Why certain choices are preferred; complexity for each scenario

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Problem list

1. **Two Sum & array pairs** — Two Sum, Two Sum II (sorted), Three Sum
2. **Sliding window** — Max subarray (Kadane), Longest substring no repeat, Min window substring
3. **Strings & palindromes** — Valid palindrome, Longest palindromic substring, Group anagrams
4. **Linked list** — Reverse list, Cycle detection, Merge two sorted lists
5. **Binary tree** — Max depth, Level order, LCA, Validate BST
6. **Graph** — Number of islands, Course schedule, Clone graph
7. **Dynamic programming** — Fibonacci, Coin change, Longest increasing subsequence
8. **Stack & queue** — Valid parentheses, Min stack, LRU cache
9. **Binary search** — Classic search, Search rotated array, Find first/last position
10. **Hash map & set** — First non-repeating character, Subarray sum equals K, Contains duplicate (within k)
